Actúa como un equipo Senior de Product Designers de Airbnb, Stripe, Google, Apple, Microsoft, Duolingo, Notion y BetterHelp.

Tu misión es rediseñar completamente la experiencia de acceso (registro, inicio de sesión y onboarding) de ASHAKids.

NO quiero un sistema cerrado donde el administrador cree todas las cuentas.

Quiero una plataforma moderna, escalable y preparada para crecer como un producto SaaS de HealthTech.

==================================================

NUEVO MODELO DE ACCESO

==================================================

Implementar un sistema híbrido.

Existen tres tipos de usuarios:

👨‍👩‍👧 Padres

👩‍⚕️ Terapeutas

🛡 Administradores

==================================================

PADRES

==================================================

Los padres pueden registrarse libremente.

No necesitan un código.

No necesitan aprobación.

Proceso:

1. Crear cuenta.

2. Verificar correo electrónico.

3. Completar perfil.

4. Agregar hijos.

5. Recibir ayuda de ASHI.

6. Comenzar a usar la plataforma.

==================================================

TERAPEUTAS

==================================================

Los terapeutas NO crean una cuenta inmediatamente.

Primero envían una solicitud para formar parte de ASHAKids.

Proceso:

Formulario de postulación.

Información profesional.

Especialidades.

Experiencia.

Número de colegiatura (si aplica).

Idiomas.

Currículum.

Documentos.

Disponibilidad.

Botón:

Enviar solicitud.

Después aparece una pantalla elegante indicando:

"Gracias por postular.

Nuestro equipo revisará tu información y te notificará cuando tu cuenta sea aprobada."

==================================================

ADMINISTRADORES

==================================================

No existe opción pública para crear administradores.

Los administradores únicamente pueden ser creados por otro administrador desde el panel interno.

No mostrar esta opción al público.

OBJETIVO FINAL

Quiero que la experiencia de acceso a ASHAKids se sienta igual de moderna que la de plataformas como BetterHelp, Duolingo o Airbnb.

El usuario debe comprender inmediatamente qué tipo de cuenta necesita, registrarse de forma sencilla y sentirse acompañado por ASHI durante todo el proceso.

El administrador deja de crear usuarios manualmente y pasa a gestionar la calidad de la plataforma.

El resultado debe transmitir una plataforma escalable, profesional, cálida y preparada para miles de usuarios.
