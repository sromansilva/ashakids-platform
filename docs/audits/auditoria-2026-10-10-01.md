## 02. Arquitectura y cambios realizados

Stack conservado: React -> HTTP/JSON -> FastAPI -> SQLAlchemy/PostgreSQL. Sin Next.js, Supabase Auth ni librerías de runtime nuevas. Se instaló httpx 0.28.1, ya declarado en requirements-dev, exclusivamente en el entorno local para las comprobaciones ASGI.

Reutilización: useAuth/AuthProvider, QueryClient, learningGames, RemoteFeedback, Btn, PublicNav/Footer, componentes inferiores, acordeón FAQ y asistente actual. WorldCards centraliza tarjetas; PublicDialog usa dialog nativo con foco, Escape y trampa de Tab; PublicIllustration aplica dimensiones, srcset y tamaños desde un manifiesto estático.

GET catálogo cambia sólo a metadatos/número de niveles. El resumen autorizado mantiene contenido jugable en mundos asignados y devuelve niveles vacíos en los demás. Cambio mínimo de contrato justificado por exposición pública de ejercicios; clientes internos ajustados. No hay cambios de tablas, migraciones ni estructura física de BD. ADR 0022 registra esta frontera. URLs privadas, APIs de intentos y reservas conservadas.

## 04. Citas, sesiones y servicios existentes

Las tarjetas de especialistas existentes eran ejemplos estáticos sin aviso. Se rotulan como demostración; no se afirma disponibilidad real ni se usan banderas ficticias para bloquear Agendar. Los accesos siguen llevando al login; Ver todos abre Especialistas. La página pública de Especialistas también identifica los ejemplos. No se inventaron fotos, profesionales, acreditaciones, testimonios ni horarios.

Agendar conserva su acceso y las reservas privadas no se modifican. La suite existente incluye componentes de agenda; no se efectuó una reserva real ni una prueba E2E de Zoom. Newsletter conserva su API y consentimiento: correo requerido, carga deshabilitada, éxito, error y recuperación comprobados con respuestas interceptadas; no entrega SMTP. Ashi continúa como Demo y WhatsApp como enlace único, sin envío ni consejo clínico nuevo.
