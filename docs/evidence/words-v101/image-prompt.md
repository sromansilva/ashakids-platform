## Prompt exacto

Create one production-ready sprite atlas for a Spanish preschool educational website ASHAKids. Landscape canvas, exactly 6 equal columns and 4 equal rows, 24 isolated full objects, one centered object in each equal cell, consistent generous padding so each object fits entirely inside its own cell. Transparent background throughout, no visible grid, no text, no letters, no numbers, no watermark. Premium friendly semi-3D clay toy illustration style matching a colorful children's language-learning landing page: rounded sculpted volumes, tasteful soft highlights, soft contact shadows, vivid readable colors, original characters, no emoji look. Every object recognizable to a 3-6 year old. Exact row-major order: row 1: orange cat, friendly brown dog, red apple, yellow banana, colorful beach ball, small blue toy car. Row 2: red and white sailboat, lush green tree, cozy little house, smiling golden sun, crescent moon, pink flower with green stem and leaves. Row 3: blue child shoe, closed purple storybook, orange fish, small blue songbird, white rabbit, orange carrot with green leaves. Row 4: golden five-point star, purple butterfly, turquoise school backpack, yellow drinking cup, round red tomato, bunch of purple grapes. All full objects facing viewer in consistent three-quarter lighting, no duplicate objects, no extra scene elements. The 6x4 arrangement and exact ordered objects are critical; each tile will become a separate interactive picture card.
