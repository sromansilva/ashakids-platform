======================================================
CONTEXTO
======================================================

ASHAKids es una plataforma web para conectar padres de familia con terapeutas infantiles certificados mediante sesiones presenciales y virtuales.

Además del servicio terapéutico, existe un módulo educativo llamado "Rincón Divertido".

Este módulo actualmente contiene cuentos, canciones, trabalenguas y adivinanzas.

Quiero reemplazar completamente ese concepto.

Ahora quiero que se convierta en un universo interactivo para niños.

Debe sentirse como si el niño entrara a una pequeña aplicación educativa dentro de ASHAKids.

No quiero una página llena de tarjetas.

Quiero una aventura.
