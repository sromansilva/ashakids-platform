Quiero rediseñar completamente la interfaz de usuario de mi proyecto llamado ASHAKids.

NO quiero pequeños cambios estéticos.

Quiero un rediseño profesional completo, moderno y coherente, manteniendo únicamente la lógica y funcionalidad existente.

El objetivo es que el proyecto tenga una apariencia similar a una startup tecnológica del 2026 enfocada en salud infantil, bienestar y terapia online.

=========================================================
CONTEXTO DEL PROYECTO
=========================================================

ASHAKids es una plataforma web donde padres de familia pueden encontrar terapeutas infantiles, reservar citas, realizar sesiones virtuales mediante Zoom y acceder a recursos lúdicos para apoyar el desarrollo de sus hijos.

El sistema incluye:

• Página principal
• Inicio de sesión
• Registro
• Dashboard del paciente
• Dashboard del terapeuta
• Perfil
• Agenda de citas
• Calendario
• Detalle de terapeuta
• Reserva de citas
• Historial
• Videollamadas
• Gestión de horarios
• Gestión de pacientes
• Rincón Divertido (juegos y actividades)
• Formularios
• Tablas
• Modales
• Alertas
• Panel administrativo
